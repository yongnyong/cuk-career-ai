# 하양이 성장·직업군 착장 이미지 제작 가이드

> **사용 허락 (2026-11-24):** 학교 공식 마스코트 지침(https://songeui.catholic.ac.kr/eng/about/mascot.do)은 디자인 변경을 금지하므로, 팀장이 학교에 직업군 착장 변형 허락을 받은 뒤 제작했다. 상업 이용은 하지 않는다.
> 원본: 학교 페이지의 공식 PNG(성심교정 과잠). 착장 13종은 ChatGPT 이미지 편집으로 만들고 배경을 지워 `web/public/hayang/*.webp`(356×514)로 넣었다.
> 진화 단계는 실제 구현 기준으로 과잠 → 직업 착장 → +자동차 → +아파트이고, 2단계부터 후광이 진해진다(웹 `src/lib/hayang.ts`, `src/components/Hayang.tsx`).

가톨릭대 캐릭터 하양이를 스킬트리 성장 캐릭터로 검토한 초안이다. 화면에는 "가톨릭대학교 캐릭터 하양이" 출처를 표시한다.

## 1. 성장 단계

| 단계 | 스킬트리 진행률 | 모습 |
| --- | --- | --- |
| 1. 학생 | 0~29% | 성심교정 과잠(남색·초록·빨강·분홍·하늘 중 사용자 선택) |
| 2. 취업 | 30~59% | 목표 직무의 직업군 착장(아래 12종 + 창업) |
| 3. 시계 | 60~89% | 직업군 착장 + 손목시계(소품 이미지 겹침) |
| 4. 아파트 | 90~100% | 직업군 착장 + 시계 + 뒤에 아파트(배경 이미지 겹침) |

## 2. 공통 조건 (모든 이미지에 똑같이)

- 기준 이미지: 공식 하양이 원본(과잠 버전) 1장을 첨부한다.
- 512×512 PNG, **투명 배경**, 정면, 기준 이미지와 같은 자세·크기·위치.
- 곱슬 흰 머리, 양 옆 갈색 뿔, 얼굴(눈·볼터치·입), 몸 비율, 굵은 남색 외곽선, 단색 채색 스타일은 **그대로**. 옷과 소품만 바꾼다.
- 그림자·배경·글자·로고 넣지 않는다(사원증·명찰은 빈칸).
- 한 장 만들 때마다 기준 이미지와 나란히 놓고 얼굴·머리가 달라지지 않았는지 확인한다. 달라졌으면 다시 생성.

### 공통 프롬프트 앞부분 (복사해서 매번 붙이기)

```
첨부한 캐릭터(가톨릭대 하양이)를 그대로 유지한 채 옷과 소품만 바꿔 줘.
곱슬 흰 머리, 양옆 갈색 뿔, 얼굴 표정, 몸 비율, 굵은 남색 외곽선, 단색 평면 채색 스타일은 원본과 똑같이.
정면 전신, 원본과 같은 자세와 크기, 512x512, 투명 배경, 그림자·배경·글자 없음.
바꿀 옷:
```
