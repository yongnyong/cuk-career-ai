# 발표 자료 초안 — 사업화·확장 (2026-11-24 회의)

서비스에 구현하지 않고 발표 슬라이드로만 다룬다. 실제 계약·연동이 없으므로 "제안·로드맵"으로 표현하고, 숫자는 가정임을 밝힌다.

## 슬라이드 A. 인증된 스킬트리 = 검증된 이력서

- **문제:** 기업은 지원자의 자격증·어학·활동을 하나하나 증빙으로 다시 확인한다. 학생은 같은 내용을 공고마다 다시 적는다.
- **CUK Career AI가 가진 것:** 학생이 스킬트리에 쌓은 노드마다 완료 상태와 증빙(자기 보고 / 증빙 첨부 / 검증됨)이 이미 기록돼 있다.
- **확장:** 이 기록을 한 장짜리 "인증 스킬트리 이력서"로 만들어 기업에 보낸다. 노드마다 인증 수준이 함께 표시된다.
- 화면 근거: 지금도 "완료 내역·증빙 인쇄"(`/print`)로 완료 노드와 증빙을 한 장으로 뽑을 수 있다.

## 슬라이드 B. 채용 플랫폼 연계 제안 (로드맵)

```
학생: 스킬트리에서 준비 → 증빙·인증 → "내 스킬트리 보내기"
                                         │
CUK Career AI: 인증 정보가 붙은 이력서 생성 ─┼─→ 잡코리아 등 채용 플랫폼(데이터 연계 제안)
                                         └─→ 기업 채용 담당자(인증 정보 바로 확인)
```

- 채용 플랫폼에는 **인증이 끝난 지원자 데이터**를 공급하는 파트너로 제안한다.
- 기업은 증빙 확인 시간을 줄이고, 학생은 한 번 쌓은 기록을 여러 곳에 쓴다.
- 연계의 전제: 인증 절차를 갖춘 기록만 보낸다(발급기관 조회 등 인증 고도화가 1순위 과제).

## 슬라이드 C. 수익 모델 (가정)

| 대상 | 모델 | 예시 |
| --- | --- | --- |
| 학생 | 인증 스킬트리 이력서 발송 건당 과금 | 건당 5,000원(가정) |
| 채용 플랫폼 | 인증 지원자 데이터 연계 제휴 | 제휴 수수료 |
| 기업 | 장기: 기업 입주·채용 공고 게시 | 게시·열람 요금 |

## 슬라이드 D. 단계별 확장

1. **지금(대회):** 가톨릭대 학생 대상 — 공고 수집, 스킬트리, 하양이 성장, 근거 챗봇.
2. **다음:** 인증 고도화(발급기관 조회), 인증 스킬트리 이력서·공유 링크, 트리 공유 커뮤니티.
3. **확장:** 채용 플랫폼 연계 제안 → 사용자가 늘면 기업 입주형 채용 플랫폼.

## 발표 때 말할 것 / 말하지 않을 것

- 말할 것: "제안할 계획", "로드맵", "가정한 가격".
- 말하지 않을 것: 잡코리아와 협의·계약이 있는 것처럼 들리는 표현, 근거 없는 시장 규모 숫자.
- 개인정보: 이력서·공유에는 학번 전체·연락처를 넣지 않고, 학생이 직접 공개를 고른 정보만 보낸다(대회 준수사항과 같은 원칙).
