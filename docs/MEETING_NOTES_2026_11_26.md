# main 통합 후 회의 확인 사항

2026년 11월 26일 현재 브랜치 `jh_261128_model`에 `origin/main`의 `3ac9b76`까지 병합했다. 충돌 시 main을 우선한다는 사용자 지시에 따라 통합했다. 다음 사항은 회의에서 논의할 대상으로 기록하며, 복원 여부는 아직 결정하지 않았다.

## 빠지거나 약해진 기능

| 항목 | 현재 상태 | 회의에서 결정할 사항 |
| --- | --- | --- |
| 공통 및 전문 트리 전환 | 내부 영역별 필터는 남아 있으나 전환 탭이 사라져 공통 영역 접근이 어려움 | main의 새 보기 방식과 영역 전환을 함께 제공할지 |
| 자격증 응시요건 입력 | 판정 로직은 유지되지만 공식 요건 충족 여부와 임상 이력을 입력하는 상세 UI가 빠짐 | 상세 화면에 입력 UI를 복원할지 |
| 취업과 창업 노드 분리 | 추가 추천은 차단하지만 main의 기본 템플릿에 있는 창업 노드를 제거하던 처리는 빠짐 | 기본 템플릿까지 관심 분야로 분리할지 |
| 노드에 연결되는 공고 | 해당 직무로 제한하고 창업 공고를 제외하던 노드별 연결 조건이 빠짐 | 공고 추천과 노드 연결의 분류 기준을 통일할지 |
| 트리 자동 배치 | 기존 ELK 화면 배치가 main의 파형, 방사형, 단계별 보기로 대체됨 | 이전 배치 복원이 필요한지 |

타입 검사와 자동 테스트 통과가 기존 UI 기능의 보존을 보장하지는 않는다. 특히 전환 탭과 응시요건 입력 UI는 통합 과정에서 놓친 회귀 사항이다.

## 유지된 작업

- 공고 DB 연결, 24개씩 페이지 표시, 브라우저 저장 최적화
- 창업 가입 대화의 선택지 제거와 서비스 설명 중심 안내
- 공고 상세의 원문 의미 단위 영역 제거
- RAG와 창업 신청서 초안 기능

## 보존과 Git 범위

- 병합 전 작업은 `backup before main integration 2026-11-26` stash로 보존했다.
- 기존 작업과 통합 보정은 아직 미커밋이며 푸시하지 않았다.
- 저장소 상위 폴더의 크롤러와 robots 검사 파일은 이번 Git 병합에 포함되지 않았다.
- 로컬 DB는 Git에서 제외되어 있으므로 코드 공유와 별도로 전달 방식을 정해야 한다.
